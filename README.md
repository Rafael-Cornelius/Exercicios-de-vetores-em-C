# Vetores — arquivo original

**Os exercícios prontos para abrir estão em [Portugol / vetores](https://github.com/Rafael-Cornelius/exercicios-portugol/tree/main/vetores).**

O ZIP deste repositório contém páginas salvas do Portugol Webstudio, não códigos em C.
Foram recuperados cinco programas completos: leitura e exibição, soma, média, maior e menor e busca de número.
As páginas “Exercicio 5” e “Exercicio 6” têm o mesmo código de busca.

- [Baixar o ZIP original](arquivos-originais/exercicios-de-vetores.zip)
- Para novos exercícios, use o [repositório de Portugol](https://github.com/Rafael-Cornelius/exercicios-portugol).

O material original permanece preservado para consulta.
